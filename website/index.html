核心功能

随心定制，自在阅读

从外观主题到交互细节，每个功能都为你的个性化需求而设计。

即点即改

渲染态下直接点选段落即可编辑，无需在预览和编辑模式之间反复切换，所见即所得。

目录导航

自动识别文档目录结构，支持快速章节跳转与定位高亮，长文档浏览不再迷路。

本地文件管理

自定义工作区路径，新建、重命名、搜索、排序一站完成。最近文件与文件夹快速访问。

数学公式

完整支持 KaTeX 数学公式渲染，行内公式与块级公式均可流畅编辑和预览。

导出与分享

支持将文档导出为 PDF、图片或 ZIP 压缩包，随时与他人分享你的写作成果。

云端同步

内置 WebDAV 和 FTP 同步支持，提供冲突提示与同步预览，多设备写作无缝衔接。

界面展示

简洁而不简单

每一个界面都经过精心设计，让个性化定制变得轻松直观。

项目开发笔记
技术栈选型

本项目基于 Flutter 框架开发，采用 Provider 进行状态管理，编辑器核心使用 Milkdown 实现。

开发进度

当前版本已完成渲染态编辑、目录导航、主题系统等核心功能。

接下来的重点是优化云同步模块的稳定性，以及完善 导出功能的排版质量。

  • 渲染态即点即改
  • 多层级目录导航
  • 粒子特效系统
