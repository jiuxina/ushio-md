Markdown 原样 round-trip —— 打开再保存，用户的文件不该被改写

编辑器把 markdown 解析成 ProseMirror 文档、再序列化回来。只要这两步不是互逆的， 用户「什么都没改」地打开再保存，文件就已经变了。设备/文档里已登记过 - 变 *、 插空行、图片 alt 被改写等现象，但从未逐条定性。 本页把每种语法单独喂进去，不做任何编辑，直接比对输出与原文是否逐字节相等。 未编辑时编辑器直接返回原文（与 App「没有修改就不写盘」一致），PASS 即表示「打开再保存不会改文件」； 被编辑过的块仍会走序列化，已知的语义等价规范化见审计文档 §4.4，不会影响未动过的内容。
