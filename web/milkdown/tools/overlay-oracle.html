HTML 块 overlay 判据 —— 收敛、占位精确、版面变化后仍贴着各自的块

旧实现把 overlay 的渲染高度回写进被隐藏的伪代码块（height !important），而伪块自身带 padding/border 且 box-sizing 是 content-box，实际占位高 = 渲染高 + padding， 每个 HTML 块多占一截（实测 252 vs 249.5 = 2.5px/块）并按块数累积。 本页面跑三组检查： A 收敛 连跑 N 次收尾，overlay 的 top/left/width 与 DOM 节点身份必须逐趟不变； B 占位精确 伪块占位高 == overlay 渲染高，且宽度等于正文宽； C 版面跟随 在文档上方插入内容把版面推下去之后，每个 overlay 仍必须 紧贴自己的伪块（误差 < 2px），内容没变的 overlay 不得被整块重建，文本不得错位。
