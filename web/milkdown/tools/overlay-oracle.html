HTML 块 overlay 收敛判据 —— 渲染收尾反复跑，位置必须不再变化

旧实现把 overlay 的渲染高度回写进被隐藏的伪代码块（height !important），而伪块自身带 padding/border 且 box-sizing 是 content-box，于是实际占位高 = 回写值 + padding。 每经过一个 html 块，其后所有块的 top 就多一截，表现为逐块递增的漂移 （实测 +8 / +24 / +32 / +48 / +56 / +72px，正是 8px 的倍数）。 本页面连跑 N 次渲染收尾，要求：① 第 2 次起每个 overlay 的 top/left/width 与上一次**完全相同**（收敛）； ② overlay 宽度等于正文宽度而不是塌成几像素；③ 伪块占位高与 overlay 实际高一致。
