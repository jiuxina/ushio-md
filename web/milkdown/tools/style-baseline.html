代码块计算样式基线 —— 「内联 !important 搬进持久 CSS」的对照检查

旧实现由 syncRenderedDom 逐个代码块写 22 条 style.setProperty(..., 'important')， 且**只作用于非 html-block 的代码块**（伪块要留给 overlay 占位，不能被加 padding-top）。 搬进 CSS 后必须逐块得到同样的计算样式：多一条会改变布局，少一条会让工具栏错位， 误加到伪块上则会让 overlay 定位再漂移。本页面把每个代码块及其 .tools / .language-picker / 自定义语言框的计算样式导出成稳定 JSON，改前改后各跑一次做 diff。
