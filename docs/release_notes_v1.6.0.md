# Release v1.6.0

## 更新日志 2026/8/26

### 修复与改进

- **悬浮按钮遮挡**：预览模式“目录”按钮不再遮挡“标题 1/标题 2”，按钮列上移到底部工具栏上方
- **搜索高亮**：正文匹配高亮改为 ProseMirror decoration，搜索后不再被编辑器重绘清除，并支持当前匹配高亮
- **搜索后输入恢复**：关闭搜索后重新聚焦编辑器并释放 Flutter IME client（Android 真机键盘恢复待复核）
- **大文件加载**：>512KB 文档支持渐进渲染，新增 15 秒首帧超时安全网，可继续等待或返回
- **编码错误**：非法 UTF-8/二进制文件给出明确错误提示，不再静默退回
- **CRLF 保留**：保存时保持文档原始换行风格，CRLF 文件不再被转成 LF
- **文件列表**：支持无扩展名文本/Markdown 文件；异常 stat 显示“未知”而非 `-1 B · 1970/1/1`
- **中文文件名**：非 ASCII 文件名统一使用原生路径构造，避免编码转换导致打不开

### 测试

- Android 12 模拟器回归：预览/编辑、搜索高亮、TOC、版本历史、自动保存、CRLF、非法编码、无扩展名与中文文件名文件
- `FileService` 编码/CRLF/二进制检测单元测试通过
- 详细结果见 `docs/QA_REPORT_2026_08_25.md`
