## 预期行为

1. 所有标题都应该正确渲染
2. 点击目录中的标题应该跳转到正确位置
3. 标题之间的内容应该正确显示
4. 相同文本的标题应该有不同的ID
5. 标题层级应该正确识别(H1-H6)

## 当前可能的问题

根据release notes:
> 文档内容中有2个以上的有效标题语法时(井号+空格),那么在他们之间的内容可能会解析错误。

请观察:
- 标题之间的内容是否正确显示
- 目录导航是否正常工作
- 编辑器渲染是否有异常
