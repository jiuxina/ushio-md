# Issue #129 PDF 公式导出修复

PDF 导出会先识别 `$...$` 行内公式和 `$$...$$` 块级公式，再通过本地 KaTeX 页面渲染为 PNG，最后将图片嵌入 `pdf` 文档。普通正文仍由 PDF 字体绘制，因此文字保持可选择。

公式页面复用应用的本地资源服务器和编辑器使用的 KaTeX 版本，不依赖网络 CDN。每次导出最多创建一个隐藏 WebView，会话按表达式、显示模式、字体大小和最大宽度缓存截图，导出完成或异常时都会释放 WebView。

代码围栏、行内代码、转义美元符号和未闭合的定界符不会被识别为公式。KaTeX 不支持或解析失败的表达式保留原始源码，避免静默丢失文档内容；WebView、字体或截图失败则让导出进入已有的失败提示路径。

货币文本（例如 `$5 and $10`）不会吞并后续独立公式，同时 `$5$`、`$10x$` 等数字开头的完整公式仍正常识别。

每次渲染先触发布局以发现公式所需字体，再等待字体加载。隐藏 WebView 调整尺寸后会重新取得截图区域和基线；尺寸必须为有限正值，原生截图单边不超过 8192 像素、总面积不超过 16777216 像素，避免异常表达式导致无限制的位图分配。

回归测试覆盖 issue 附件中的三角函数表达式、下标、列表与表格中的行内公式、块公式、重复公式缓存、代码和转义美元符号、货币与数字公式边界，以及截图失败时的资源释放。Web 定向测试验证字体发现早于等待、视口调整后的重新测量和无效尺寸拒绝。实际 Android 隐藏 WebView 截图仍需结合设备导出验证。
