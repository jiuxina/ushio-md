# 编辑页交互与后台保存修复（#134–#137）

日期：2026-11-16。

- #134：主题与头部、键盘、工具栏尺寸在 `init_doc` 前发送。初始尺寸直接随组件传入，第一行顶部留白由 Web 容器统一计算。
- #135：源码／渲染编辑切换固定在顶栏保存按钮旁。关闭悬浮按钮也能切换；悬浮目录按钮继续遵循原设置。
- #136：沿用现有“自动保存”开关。开启时，离开前台和锁屏立即保护待保存内容；关闭时保持手动保存。只打开未修改的文档不写盘。
- #137：系统菜单“全选”进入 ProseMirror 的整篇选区，包括从代码块中调用。链接输入框等独立输入控件保留原生局部选区。

保存前先同步取回 WebView 尚未发布的输入，覆盖 Milkdown 自身监听防抖与 Flutter 合并防抖。保存基线与版本快照来自实际写入的正文快照，写盘期间的新输入继续保持未保存状态。后台事件合并处理；返回退出时等待最新内容保存成功。同步失败时保留当前页面和未保存标记。

键盘尺寸使用当前 Flutter View 的物理 inset 换算为逻辑尺寸，合并同帧通知并过滤重复桥命令。WebView 保持固定尺寸，工具栏仅在实际显示时计入遮挡。
