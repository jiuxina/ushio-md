# 预览/编辑功能 QA 报告（模拟器）

- 日期：2026-08-25
- 应用：汐 Markdown 编辑器 v1.5.13（包名 `com.ushiomd`）
- 设备：`emulator-5556` / Android 12 / 1080x1920
- 测试范围：预览页与编辑页（含编辑器内菜单：搜索、快捷键帮助、导出 PDF、版本历史；文件列表仅用于打开测试文件）
- 判定依据：uiautomator 层级树、WebView CDP DOM、`logcat`、磁盘文件哈希/内容
- 说明：视觉桥接口当天多次返回 `429 Too Many Requests`，截图已留存但未进行视觉判定；所有 UI 布局结论均来自层级树坐标与日志。

## 测试方法

- 用 `uiautomator dump` 读取 Flutter/WebView 的可访问性节点与坐标。
- 用 WebView CDP（`build/cdp_helper.py`）读取 ProseMirror DOM、执行输入并统计高亮节点。
- 用 `adb shell input tap/text/keyevent` 模拟点击、键盘输入、返回键。
- 用 `md5sum` / `cat` 校验磁盘文件是否被自动保存或改写。
- 通过 `logcat` 检查 `[NAV]`、`[EDITOR]`、`[WEBVIEW]`、`[JS]` 等日志。

## 通过项

### 预览与渲染

- ATX/Setext 标题、段落、无序/有序列表、任务复选框、引用、代码块、表格、硬换行、KaTeX、图片、HTML 块均能正常渲染。
- 预览态点击段落可进入行内编辑；粗体、斜体、删除线、撤销/重做、任务框勾选、表格单元格编辑可用。
- 链接点击会打开 Chrome，返回可回到编辑器；图片点击可打开大图预览并可关闭。
- TOC 可打开、列出多个标题、点击标题跳转并自动关闭。
- 编辑态输入的原始 Markdown 切回预览后能正确渲染。

### 搜索

- 搜索计数、上一个/下一个跳转正常。
- “区分大小写”“全词匹配”“正则表达式”三个开关均生效：
  - `Autosave` 默认命中 1，开启区分大小写后变 0。
  - `e` 默认命中 5，开启全词匹配后变 1。
  - `autosave|extra` 开启正则后命中 2。

### 编辑器菜单

- 快捷键帮助面板可打开、展示保存/撤销/重做/搜索/加粗/斜体/删除线快捷键，并可关闭。
- 版本历史可列出版本、进入新旧对比（+/- 行）、回退版本并自动备份（回退后版本数从 9 增至 11）。
- 导出 PDF 会调起系统选择器；当前模拟器无 PDF 处理应用，选择器提示“没有应用可执行此操作”，属于环境限制。

### 自动保存

- 设置“保存间隔 15 秒”后，编辑内容不点保存，等待 15 秒磁盘文件已更新。
- 编辑内容后按返回键，磁盘文件立即更新（退出时保存生效）。

### 编辑页工具栏

- 编辑页可直接输入原始 Markdown。
- 粗体/斜体/删除线/标题按钮可插入占位内容（如 `**文本**`、`*文本*`、`~~文本~~`、行首 `# `）。

### 边界与压力

- 空文件、纯空格文件、Unicode 文件、畸形 Markdown、深层嵌套、300x8 大表格、300KB 超长单行、BOM 文件、625KB 大代码块均可打开/编辑，未崩溃。
- 快速连续点击菜单/工具栏 24 次无崩溃。
- 按 Home 后恢复，未保存内容保留且磁盘不变；强杀进程后重启，小文件可恢复。

## 发现的问题

### P1：预览模式下“标题 1/标题 2”被“目录”悬浮按钮遮挡

- 复现步骤：
  1. 打开任一含段落的文件，默认进入预览模式并聚焦编辑器。
  2. 点底部工具栏“标题 1”按钮中心（坐标约 `870,1824`）。
- 实际：右侧“目录”悬浮按钮（层级树范围 `[852,1692]-[1008,1848]`）先命中，打开“目录”面板；标题未应用。
- 期望：将当前段落转换为 H1。
- 证据：点击后 dump 出现 `目录 / H1 ...`；同一坐标在编辑模式下不会打开目录，而是正常在行首插入 `# `。工具栏“标题 1”显示范围为 `[798,1758]-[942,1890]`，与悬浮按钮重叠。

### P2：使用内联搜索后，系统键盘事件无法再输入到 WebView 编辑器

- 复现步骤：
  1. 打开文件进入预览页，先直接输入文字（成功）。
  2. 打开右上角菜单 → 搜索，输入关键词后关闭搜索。
  3. 再次点击编辑器并发送键盘输入。
- 实际：`adb input text` 和单字符 keyevent 均不进入文档；`dumpsys input_method` 仍显示 IME 已连接 `InAppWebView`（`mInputShown=true`、`mServedView=InAppWebView`），但 DOM/EditText 内容不变。
- 期望：关闭搜索后编辑器恢复接收键盘输入。
- 备注：此时通过 CDP `Input.insertText` 仍可插入，说明问题集中在 IME/键盘事件链路；可能受模拟器输入法影响，建议真机复核。

### P3：搜索计数正常但编辑区没有高亮

- 复现步骤：
  1. 预览页打开搜索并输入 `e`。
  2. Flutter 侧显示 `1/5` 且上下文片段正常。
- 实际：CDP 查询 `.ushio-search-highlight` 与 `.ushio-search-highlight-active` 均为 0，ProseMirror 段落 HTML 中没有高亮 span。
- 期望：正文中匹配文字应有可见高亮（代码中已定义 `.ushio-search-highlight` 样式）。

### P4：编辑页按一次返回只保存不退出

- 复现步骤：
  1. 编辑页修改内容但不点保存。
  2. 按一次返回键。
- 实际：状态栏变为“刚刚保存”，磁盘文件已更新，但页面仍停留在编辑页；需再按一次返回才回到文件列表。
- 期望：一次返回应退出编辑页，或明确弹出“保存并退出/放弃”选择。

### P5：5.8MB 大文件长时间停留在“正在加载内容...”

- 复现：打开 `qa_huge.md`（5.8MB）。
- 实际：数分钟未完成首屏渲染，WebView CDP 无响应；Flutter 界面可返回文件列表。
- 期望：大文件应有加载进度或可取消，不应无限期停留在加载态。

### P6：二进制/非法 UTF-8 文件打开失败且无用户提示

- 复现：打开 `qa_binary.md`、`qa_invalid_utf8.md`。
- 实际：`logcat` 输出 `[NAV] ERROR: FileSystemException ... utf-8`，界面直接退回文件列表，无错误提示。
- 期望：给出可读错误提示，或提供忽略/二进制处理选项。

### P7：CRLF 文件首次编辑保存后换行被转成 LF

- 复现：打开 `qa_crlf.md`（CRLF），修改后保存。
- 实际：磁盘文件换行变为 LF。
- 期望：未主动选择转换时保持原换行风格。

### 其他观察

- 中文文件名在文件列表显示 `-1 B · 1970/1/1`，点击后 `logcat` 报 `File not found ... �߽� ���� �ļ�.md`（该问题属于文件列表页，作为附带发现记录）。
- 无扩展名文件（`qa_noext`）不出现在“我的文件”列表。
- 自动化通过 JS bridge 直接触发 `set_heading` 后，WebView JS 主线程出现 CDP 评估超时，随后保存会让编辑区停留在“正在加载内容...”，重启应用后恢复。该路径不是正常用户入口，但说明 JS bridge 命令异常时缺少恢复机制，建议作为低优先级风险跟踪。
