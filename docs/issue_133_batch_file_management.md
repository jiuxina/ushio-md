# 文件列表批量管理（#133）

“我的文件”和进入文件夹后的列表支持选择文件、文件夹，进行全选、反选、移动或删除。首页置顶项及历史记录不提供批量选择入口。

## 使用方法

1. 点击列表标题栏的“选择项目”图标，点击项目或复选框调整选择。
2. “全选”和“反选”只作用于当前显示的列表。搜索时会取消不再显示的项目选择。
3. 点击“移动”后，通过系统目录选择器指定目标。点击“删除”后，需要确认一次不可撤销的删除操作。
4. 返回键或关闭按钮先退出选择模式。处理期间不接受重复操作；取消目录选择或删除确认不会改动文件。

## 失败与引用处理

- 每项独立处理，完成后显示成功与失败数量，失败项继续保持选中，并列出路径与原因。
- 目标存在同名文件、文件夹或对应版本历史时跳过该项，不覆盖、不自动改名。文件夹不能移入自身或子目录。
- 移动文档会同时移动 `.versions/<文件名>/` 历史，并修正文档和版本文件路径。移动文件夹会修正其内部历史中的路径。
- 图片不会占用或移动同名文档的版本历史。对于 `note.md` 与 `note.markdown` 这类共用历史目录的文件，移动前检查元数据所属路径；仅属于其他文档的历史留在原处，混合所属或无法确认所属的历史会阻止该项移动，避免带走其他文档的历史。
- 如果移动历史失败，会尝试把文件和历史回退到原位置。跨文件系统的重命名失败会保留源项目，并显示失败原因。
- 已完成项目同步更新最近访问、置顶、最后打开路径与内容缓存。元数据保存异常会明确提示，文件列表仍重新加载。

## 定向验证

自动验证覆盖混合选择、反选、搜索取消隐藏选择和退出选择模式，以及移动历史、同名冲突、子目录目标、历史冲突、历史移动失败回退、损坏历史预检、部分删除与路径引用更新。还覆盖图片与文档共享文件名主体，以及 `.md`、`.markdown` 历史所属与混合所属的保护。

```text
flutter test --no-pub test/services/batch_file_service_test.dart test/providers/batch_path_metadata_test.dart
flutter test --no-pub test/screens/folder_batch_selection_test.dart test/widgets/file_tile_test.dart
```

设备验收使用专门创建的合成文件夹，分别检查移动后文件内容与历史仍可读取、失败项不会覆盖目标，以及取消操作后内容保持原样。
