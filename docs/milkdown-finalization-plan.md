# Milkdown 迁移收官计划（Finalization Plan）

## 背景

当前仓库已完成 Milkdown 单内核接线与资产收口，但迁移验收仍缺少统一的真机回归与性能基线。  
本计划用于补齐“可重复验证”的最后一环，完成迁移收官。

## 目标

1. 建立可执行的真机回归清单（覆盖 Android 主版本 + WebView 版本差异）。
2. 固化性能基线（首屏可编辑时间、长文档输入响应、滚动流畅度）。
3. 将验收结果沉淀为可复用文档，作为后续升级和回归标准。

## 分步计划

### Step 1（本次完成）— 建立真机回归清单模板

- 新增统一回归清单，覆盖：
  - 编辑页初次加载、主题切换、内容回写；
  - 链接点击、任务列表勾选、命令工具栏；
  - 全屏预览截图链路；
  - 不同 Android/WebView 版本组合。

### Step 2 — 固化性能采样方法

- 定义采样文档规模（小/中/大）；
- 统一采样指标与记录格式；
- 明确通过阈值与回归判定规则。

### Step 3 — 首轮实测并回填结果

- 按清单执行首轮真机回归；
- 记录性能基线；
- 将风险项写入迁移状态文档。

## 本次落地项

- ✅ 已完成 Step 1（新增真机回归清单模板文档）。
- ⏭ Step 2/3 待执行（需要真实设备与版本矩阵）。
